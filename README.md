# Temir yo'l transportida audit — Uslubiy ko'rsatma
# Railway Transport Audit — Methodological Guide

## Hujjat haqida / About the Document

**nimadur.docx** fayli — Toshkent Davlat transport universitetining 5230900 – «Buxgalteriya hisobi va audit» ta'lim yo'nalishidagi 4-bosqich bakalavriat talabalari uchun mo'ljallangan «Temir yo'l transportida audit» fanidan kurs va mustaqil ishlarni bajarishga doir uslubiy ko'rsatma.

**nimadur.docx** is a methodological guide for 4th-year bachelor's students in the 5230900 – "Accounting and Audit" programme at Tashkent State Transport University, covering course and independent work tasks for the "Railway Transport Audit" subject.

---

## Tarkib / Contents

1. **Kirish / Introduction** — Kurs ishining maqsadi va tuzilishi haqida ma'lumot.
2. **Nazariy qism / Theoretical section** — Variantga muvofiq nazorat savollariga yozma javob.
3. **Amaliy qism / Practical section**:
   - Vagon deposi ishi ko'rsatkichlarining bahosi
   - Kassa va kassa operatsiyalari tekshiruvi
   - Moddiy boyliklar tekshiruvi
   - Moliyaviy natijalarni tekshirish
4. **Xulosa / Conclusion** — Auditorlik xulosasi va hisobotini tuzish.
5. **Ilovalar / Appendices** — Variantlar bo'yicha amaliy ma'lumotlar (variant 18 va boshqalar).

---

## Foydalanish bo'yicha yo'riqnoma / How to Use

1. `nimadur.docx` faylini Microsoft Word, LibreOffice Writer yoki boshqa mos dastur orqali oching.
   Open `nimadur.docx` with Microsoft Word, LibreOffice Writer, or any compatible office application.

2. O'z variant raqamingizga mos ma'lumotlarni ilovalardan tanlang (masalan, Variant 18).
   Select data matching your variant number from the appendices (e.g., Variant 18).

3. Ko'rsatmalarga muvofiq kurs ishining har bir qismini bajaring.
   Complete each section of the course work according to the instructions.

4. Auditorlik hisoboti va xulosasini O'zbekiston Respublikasi Auditorlik faoliyati milliy standarti №70 asosida rasmiylashtiring.
   Prepare the audit report and conclusion in accordance with National Auditing Standard No. 70 of the Republic of Uzbekistan.
